## 🌍 Section 2: Product Vision & Documentation

### 🧐 The Problem
Waste management in cities like Navi Mumbai faces three critical issues:
1.  **Apathy:** Citizens ignore trash because "it's not their job."
2.  **Ineffective Volunteerism:** Manual labor drives (like NSS) have low retention rates.
3.  **Data Gaps:** Municipal authorities (NMMC) lack real-time data on "Black Spots" (garbage heaps).

### 💡 The Solution: GeoClean
GeoClean is a hyper-local web platform that gamifies cleanliness. We don't just ask people to clean; we make it profitable and competitive.

* **Gamification:** Students compete in Department vs. Department wars for "GeoPoints."
* **Incentivization:** "GeoCoins" can be redeemed for discounts at local businesses (Barter Model).
* **Escalation:** Unresolved reports are auto-escalated to public social media channels to ensure accountability.

### 🛠️ Tech Stack
* **Frontend:** HTML5 (Semantic), CSS3 (Animations, Flexbox, Grid), JavaScript (DOM Manipulation).
* **Design System:** Custom "Cyber-Nature" Aesthetic (No external CSS frameworks used).
* **Version Control:** Git & GitHub Organization.

### 🚀 Key Features
| Feature | Description |
| :--- | :--- |
| **Heatmap Reporting** | Users can drop pins on dirty spots to alert authorities. |
| **Leaderboard** | Real-time ranking of top volunteers and college departments. |
| **The "Cool-Down" Mode** | Designed for joggers to report waste without breaking their workout flow. |
| **Smart Auth** | Seamless toggle between Login and Registration for fast onboarding. |
